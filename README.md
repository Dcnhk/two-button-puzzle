## 复现

```bash
python3 两按钮关卡_最优解_复现.py
```

依赖 `numpy`、`scipy`；约 60 秒。输出逐项对应定稿 §2.3（`F₀` 与策略表）、§2.4（网格收敛）、§4（天花板与 Cramér 根）、§3（CRN 配对与 Garwood 上沿）、§5.3（Wald 过冲、合拢几何）、§5.2/§6（静态规则仿真、均值恒等式）。

**两点口径说明**（以下差异属预期，不是 bug）：

1. 定稿 §6 的 `±0.0006` 天来自更大的主池；脚本用单批 1M 局验证量级，SE 不同。静态规则采用「相等时固定点左」的 tie-break，与定稿 §6 统计所用的「相等时点累计点击较少侧」为二阶替换，差异远小于该误差棒（定稿 §5.2 已注明）。
2. CRN 配对脚本使用独立种子 `(777, 20261105)`，分歧局数与定稿自身种子组的 20 / 18 局不逐字相同；脚本同时打印定稿口径的 Garwood `k=20 → 2.511 秒` 与 `k=18 → 2.306 秒`，量级对齐。DP `F₀`、命中率天花板、`ρ*` 严格一致，静态规则统计允许波动。

## 引用时请勿过度声明

「这份文档没问题」**不等于**以下三件事：

1. **上界不是无条件数学证明。** 它是 95% 的泊松统计上沿（CRN 配对 + Garwood），下界才是解析精确的；`14.129454` 严格说是**松弛 DP 的精确下界**加上统计一致记号。
2. **θ=73 不是 DP 的最优性输出。** DP 无 θ 参数；θ 来自静态规则族扫描（E 腿平坦集 `{73,74}` + 命中率破平局）。
3. **启发级条目仍是启发。** 「每局 ≤2 天」的结构解释、`N(θ)` 几何、Cramér 衰减旁证等均为启发；文档已如实自标，这是特性，不是缺陷。
